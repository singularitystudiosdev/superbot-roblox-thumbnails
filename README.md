# superbot-roblox-thumbnails

Standalone copy of the `superbot-roblox-thumbnails-af4c3c6b` creative from
`singularitystudiosdev/superbot-ad-gallery` (commit c296385).

Static site: open `index.html` through any server (`npm run serve`, then
http://localhost:5281/). `?t=<seconds>` freezes a frame, `?controls=1` shows the
key hint. Verify scripts in `tools/` need `npm install` (Playwright).
